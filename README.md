# Tess Zhao LCSW — Static Website

This is a self-contained static website suitable for GitHub Pages or ordinary static hosting. No build step is required.

## Deploy

Upload the contents of this folder to the repository root (or to the GitHub Pages publishing directory), then enable GitHub Pages. `index.html` is the homepage.

## Scheduling

All consultation calls-to-action point to:

https://tidycal.com/tesszhaolcsw/initialconsult

## Before switching DNS / cancelling Squarespace

Verify the production domain, HTTPS, contact links, scheduling link, privacy/HIPAA text, and all pages on desktop and mobile. Keep an independent backup of this ZIP/repository.


## Visual refresh
This build includes an editorial, premium therapy-site visual layer with portrait-led hero treatment, glass navigation, responsive orbit framing, elevated cards, and reduced-motion-aware reveal animation.
